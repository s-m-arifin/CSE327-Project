## About the Project

A community-driven web platform that helps people in Bangladesh understand typical local fares and prices and discover everyday places in unfamiliar areas. Users can report transport fares and prices, add places, write reviews, save favorites and upload photos, while administrators moderate the content.

## Tech Stack

- Frontend: React.js
- Backend: Django, Django REST Framework
- Database: PostgreSQL
- Image hosting: Cloudinary
